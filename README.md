# Sorting Algorithm Visualizer

An interactive **Sorting Algorithm Visualization Website** that helps users understand how different sorting algorithms work through real-time visual animations.

The website provides a visual representation of the sorting process, making it easier to understand the logic and behavior of different algorithms.

## 🚀 Features

* 📊 Visualize sorting algorithms step by step
* 🎨 Interactive and user-friendly interface
* 🔢 Generate and sort arrays of different sizes
* ▶️ Watch sorting algorithms in action
* 🔄 Generate new random arrays
* ⏱️ Adjustable sorting speed
* 📈 Compare the working of different sorting algorithms
* 💻 Responsive design for different screen sizes

## 🧮 Sorting Algorithms

The project currently supports **5 sorting algorithms**:

| Algorithm      |  Best Case | Average Case | Worst Case | Space Complexity |
| -------------- | ---------: | -----------: | ---------: | ---------------: |
| Bubble Sort    |       O(n) |        O(n²) |      O(n²) |             O(1) |
| Selection Sort |      O(n²) |        O(n²) |      O(n²) |             O(1) |
| Insertion Sort |       O(n) |        O(n²) |      O(n²) |             O(1) |
| Merge Sort     | O(n log n) |   O(n log n) | O(n log n) |             O(n) |
| Quick Sort     | O(n log n) |   O(n log n) |      O(n²) |         O(log n) |

### 1. Bubble Sort

Bubble Sort repeatedly compares adjacent elements and swaps them if they are in the wrong order.

**Time Complexity:** O(n²)
**Space Complexity:** O(1)

### 2. Selection Sort

Selection Sort repeatedly finds the smallest element from the unsorted portion and places it at the correct position.

**Time Complexity:** O(n²)
**Space Complexity:** O(1)

### 3. Insertion Sort

Insertion Sort builds the sorted array one element at a time by inserting each element into its appropriate position.

**Time Complexity:** O(n²)
**Space Complexity:** O(1)

### 4. Merge Sort

Merge Sort uses the **Divide and Conquer** technique. It divides the array into smaller parts, sorts them, and then merges them together.

**Time Complexity:** O(n log n)
**Space Complexity:** O(n)

### 5. Quick Sort

Quick Sort uses the **Divide and Conquer** technique by selecting a pivot and partitioning the array around it.

**Average Time Complexity:** O(n log n)
**Worst Case:** O(n²)
**Space Complexity:** O(log n) average
